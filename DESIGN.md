# TrackMe Driver UI

The source of truth is `src/theme/tokens.js`, documented in `docs/redesign/STYLEGUIDE.md`. Use Signal blue for primary actions and live state, navy ink for high-contrast text, cool page/card surfaces, the 4-point spacing scale, 8-point controls, 12-point cards, and Inter. Communication controls keep fixed positions, support font scaling, and use at least 56 dp for pressure-sensitive actions.
